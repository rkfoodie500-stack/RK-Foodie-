Supabase Database Setup Guide

প্রথমবার কানেক্ট করার আগে এই টেবিলগুলো তৈরি করতে হবে।

Supabase Dashboard → SQL Editor-এ নিচের SQL চালাতে পারো। Public website-এ পড়ার অনুমতি এবং শুধু admin-এর লেখার অনুমতি RLS policy দিয়ে নিরাপদে সেট করো।

create table if not exists public.foods (id text primary key, name text not null, price numeric not null default 0, category text, store text, ingredients text, description text, image_url text, available boolean default true, created_at timestamptz default now());
create table if not exists public.banners (id text primary key, title text, subtitle text, image_url text, enabled boolean default true, sort_order int default 0);
create table if not exists public.categories (id text primary key, name text not null);
create table if not exists public.stores (id text primary key, name text not null, description text default '');

নিরাপত্তা: RLS অন করো। anon key frontend-এ ব্যবহারযোগ্য, কিন্তু write access RLS দিয়ে admin authenticated user-এ সীমাবদ্ধ রাখো। এই prototype-এ Supabase Auth login এখনও যোগ করা নেই, তাই public write policy খুলে রেখো না।
